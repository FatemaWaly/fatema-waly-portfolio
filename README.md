# Fatema Waly — Portfolio

A responsive, static portfolio for software engineering applications in the UK.

## Files

- `index.html` — page content and metadata
- `styles.css` — responsive visual design
- `script.js` — mobile navigation

## Preview locally

Open `index.html` in a browser. No build step or package installation is required.

## Publish

Upload this folder to a static hosting service such as GitHub Pages, Netlify, or Vercel. The contact section includes Fatema's email address, phone number, LinkedIn, and GitHub links.
